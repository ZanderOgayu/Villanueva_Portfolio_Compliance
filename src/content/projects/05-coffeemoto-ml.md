## 1. Mission Briefing
Developed as an Integrative Programming and Technologies initiative, this project trains predictive machine learning models to forecast consumption patterns, consumer demand trends, and resource allocation for Coffeemoto.

## 2. Methodology & Pipeline
* Preprocessed multi-variable sales and temporal datasets.
* Evaluated classification and regression algorithms to optimize inventory purchasing schedules.
* Exported packaged runnable project files for peer validation and inference testing.
