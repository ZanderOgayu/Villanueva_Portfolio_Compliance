## 1. Mission Briefing
**The Fifth Stage** is an atmospheric game title created in collaboration with the Haraya Studios team and published commercially on [itch.io](https://harayastudios.itch.io/the-fifth-stage). The game explores themes of psychological progression through evocative environmental storytelling and interactive mechanics.

## 2. Technical Implementation
* Built using the Unity game engine and C# component scripts.
* Implemented custom state machines controlling player movement, narrative trigger zones, and atmospheric audio queues.
* Optimized 2D sprite rendering pipelines for fast desktop and browser execution.
