## 1. Stack Recommendation & Strategic Rationale

### 1.1 Recommended Stack
* **Framework:** **Astro 4.x / 5.x** (Static Site Generation mode).
* **Styling:** Custom CSS with CSS Custom Properties (implementing the Arknights Design System), organized via modular component styles.
* **Content Management:** Astro Native Content Collections with Zod Schema Validation.
* **Asset Handling:** Sharp / Astro Image optimization pipeline (automatic WebP conversion, responsive `srcset`, and zero-layout-shift image dimensions).
* **Hosting:** **Cloudflare Pages** (Primary - Unlimited Bandwidth) or **Vercel** (Secondary - Automated Preview Deployments).

### 1.2 Why This Overhaul Is Recommended
1. **Zero Client-Side JavaScript Overhead:** Unlike Next.js, Astro renders 100% pure static HTML and CSS by default. This guarantees a **100/100 Lighthouse Performance** score even on slow mobile connections.
2. **Effortless Document & Report Expansion:** OJT reports, project case studies, and certificates live in clean Markdown (`.md`) files. Adding a new OJT report is as simple as creating a file in `src/content/ojt/my-report.md`.
3. **Data-Driven Skills Management:** Skills are decoupled from HTML markup into a clean JSON/YAML file. Adding, reordering, or recategorizing any skill requires updating a structured data file—never touching HTML tags or layout code.
4. **Beginner-Friendly Transition:** Astro files (`.astro`) look and feel identical to standard HTML files with a simple top fence (`---`) for component logic.

## 4. How to Add New OJT Reports & Content in the Future

Once migrated, adding an OJT report or case study is completely automated and requires zero HTML modification.

### 4.1 Step-by-Step Workflow to Add a New OJT Report
1. Open the folder: `src/content/ojt/`.
2. Create a new markdown file, e.g., `src/content/ojt/internship-company-x.md`.
3. Add the YAML frontmatter at the top of the file:

```markdown
---
title: "IT Support & Systems Engineering On-the-Job Training"
company: "Laptop and PC Outlet"
location: "Valenzuela City, Philippines"
period: "January 2023 – April 2023"
role: "Technical Operations & Client Outreach Intern"
coverImage: "/images/ojt/lpo-cover.webp"
pdfDownload: "/documents/ojt/LPO_OJT_Report_Signed.pdf"
metrics:
  - label: "Client Outreach"
    value: "100+ Contacts"
  - label: "Hardware Diagnostics"
    value: "50+ Laptops"
  - label: "Duration"
    value: "300 Hours"
tags: ["IT Support", "Hardware Diagnostic", "Client Outreach", "Email Campaigns"]
order: 1
---

## 1. Executive Summary
During my 3-month technical attachment at Laptop and PC Outlet...

## 2. Key Responsibilities & Contributions
- Diagnosed hardware issues on customer laptops...
- Coordinated B2B email outreach campaigns...

## 3. Technical & Professional Growth
This on-the-job training sparked my passion for software engineering...
```

4. **Result:** Astro automatically validates the frontmatter, creates the URL `/ojt/internship-company-x`, generates the page layout with Arknights styling, updates the OJT index page, and creates the PDF download button automatically.

## 6. How to Deploy Again for Free

### Option A: Cloudflare Pages (Recommended — 100% Free, Unlimited Bandwidth)
1. Push your repository to GitHub:
   ```bash
   git add .
   git commit -m "feat: complete arknights portfolio redesign with astro"
   git push origin redesign
   ```
2. Log into [Cloudflare Dashboard](https://dash.cloudflare.com/) and navigate to **Workers & Pages**.
3. Click **Create Application** → **Pages** → **Connect to Git**.
4. Select your GitHub repository (`ZANDER PORTFOLIO`).
5. In **Build Settings**:
   * **Framework Preset:** `Astro`
   * **Build command:** `npm run build`
   * **Build output directory:** `dist`
6. Click **Save and Deploy**.
7. Cloudflare automatically builds your site, assigns a free `*.pages.dev` domain with SSL, and redeploys automatically whenever you push new commits.

### Option B: Vercel (Alternative — Free Hobby Tier)
1. Log into [Vercel](https://vercel.com/) with GitHub.
2. Click **Add New Project** → Import `ZANDER PORTFOLIO`.
3. Vercel automatically detects Astro and configures the build command.
4. Click **Deploy**. Your site will be live at a free `*.vercel.app` domain.
